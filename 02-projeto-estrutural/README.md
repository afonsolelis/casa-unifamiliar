## 🎯 Objetivos
- Garantir segurança estrutural da edificação
- Otimizar custos de materiais
- Cumprir normas técnicas (NBR 6118, NBR 6120)
- Facilitar execução da obra
- Garantir durabilidade da estrutura

## 📊 Especificações Técnicas
- **Sistema estrutural**: Concreto armado
- **Concreto**: C25 (fck = 25 MPa)
- **Aço**: CA-50 (fy = 500 MPa)
- **Fundações**: Sapatas e vigas baldrames
- **Lajes**: Lajes maciças de concreto
