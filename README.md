# 🏠 Casa Unifamiliar - Projeto Estrutural

## 📋 Visão Geral

Este repositório contém toda a documentação, especificações e projetos para a construção de uma casa unifamiliar. O projeto abrange desde a concepção arquitetônica até a execução estrutural, incluindo todos os aspectos técnicos, legais e de engenharia necessários.

## 🎯 Objetivos do Projeto

- Desenvolver uma casa unifamiliar funcional e sustentável
- Atender às necessidades habitacionais da família
- Cumprir todas as normas técnicas e legais
- Otimizar custos e prazos de execução
- Garantir qualidade e durabilidade da construção

## 🏗️ Especificações Técnicas Principais

### Estrutura
- **Sistema estrutural**: Concreto armado
- **Fundações**: Sapatas e vigas baldrames
- **Lajes**: Lajes maciças de concreto
- **Pilares**: Concreto armado
- **Vigas**: Concreto armado

### Materiais
- **Concreto**: C25 (fck = 25 MPa)
- **Aço**: CA-50 (fy = 500 MPa)
- **Alvenaria**: Blocos cerâmicos
- **Cobertura**: Telhas cerâmicas
- **Pisos**: Cerâmica e porcelanato

### Instalações
- **Hidrossanitária**: Tubos PVC e conexões
- **Elétrica**: Cabos e fios conforme NBR 5410
- **Telefonia**: Infraestrutura para telecomunicações
- **Segurança**: Sistema de segurança básico
